# Third-party code in `@floorsupply/sdk-solana`

No third-party source is copied into this package. What it ships beside its own TypeScript:

| Path | What | Source | Licence |
|---|---|---|---|
| `wasm/floor_quote_bg.wasm` | the quoter, compiled for `wasm32-unknown-unknown` | built by `scripts/build-wasm.sh` from `rust/crates/floor-quote-wasm` (this repository's `floor-quote`, `floor-math`, `floor-types` and the Carpenter crates `carpenter-quote`, `carpenter-types`, `carpenter-clmm-math`), the Rust standard library, `borsh` 1.8.1, `bytemuck` 1.25.2, `uint` 0.9.5 and `wasm-bindgen` 0.2.128 | Apache-2.0 (this repository, the Carpenter crates); `carpenter-clmm-math` is Apache-2.0 AND MIT (see `NOTICE`); the Rust standard library, `borsh`, `uint`, `wasm-bindgen`: MIT OR Apache-2.0; `bytemuck`: Zlib OR Apache-2.0 OR MIT |
| `wasm/floor_quote.js`, `wasm/*.d.ts` | the JavaScript glue and its types | generated by `wasm-bindgen-cli` 0.2.128 (`--target web`) | MIT OR Apache-2.0 (wasm-bindgen's output) |
| `idl/*.json` | the `floor_hook`, `floor_launch`, `floor_holders`, `floor_vesting` IDLs (interface descriptions; no program source) | generated by `anchor idl build` | — |
| `src/generated/client/` | the programs' clients | generated by Codama (`@codama/renderers-js` 2.4.0) from `idl/` | Apache-2.0 |

`NOTICE` reproduces `carpenter-clmm-math`'s notice, which the compiled quoter carries.
